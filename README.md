# project_RPG
> Uma ideia de projeto que está em desenvolvimento, sobre um rpg e ou que pode ser usado como uma base para um RPG, online de turnos no futuro. Porém um modelo, de estilo: Tabuleiro e RPG de Turnos.
<br>
Com uma pegada de template sendo um livro, e dentro detalhando as aventuras, bases, níveis, habilidades, classes entre outras coisas.<br>
 Pretendo trabalhar com IA generativa dentro do sistema para que ele cresça e consiga se auto controlar.

# Como iniciar o projeto em sua máquina
Após dar o git clone na pasta de sua preferência<br>
Irá abrir o terminal dentro desta pasta<br>
Rode os seguintes comandos

### "Lembrando que neste projeto está sendo usado o Docker para o banco de dados"
// Ainda verei o passo a passo para conexão, mas pode usar o prisma cli, para verificar o banco de dados.

```
npm i // Passo 1
npx prisma init // Passo 2
npx primsa migrate // Passo 3
npm start // Passo 4
```
